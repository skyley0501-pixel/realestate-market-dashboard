# 0001: Phase1では駅検索・駅情報を提供しない

- ステータス: 承認済み
- 日付: 2026-07-26

## コンテキスト

`prisma/schema.prisma`には`Station`モデルと`Transaction.stationId`（nullable）が定義されているが、データ取得元である国土交通省「不動産情報ライブラリ」不動産価格情報取得API（XIT001）のレスポンスには最寄駅名・駅までの距離が含まれない（`station`パラメータは検索条件としては使えるが、結果に駅情報が返らないことをDay6で確認済み）。

このため、`Transaction.stationId`は現状すべて`null`のままであり、駅単位の検索・表示を行うUIやドキュメントを整備すると「実装されているように見えて機能しない」状態になり、ポートフォリオとしての完成度を損なう。

## 決定

- Phase1（MVP）では、駅検索・駅単位の一覧表示・詳細ページでの最寄駅表示は提供しない
- `Station`モデルと`Transaction.stationId`はスキーマ上残すが、UI・APIレスポンスでは積極的に使用しない
- 駅情報が必要になった場合は、将来的に国土数値情報（駅データ）等の別データソースと、住所・町名ベースの突合処理を追加する（Phase2以降で検討）

## 影響

- `TransactionRepository.search`は`stationId`によるフィルタを技術的には受け付けられるが、実データが常にnullのため実質使用不可
- README・APIドキュメント・UIに「駅検索」を記載しない
- 面接等で説明する際は「外部APIの制約により意図的にスコープ外とした」と説明できる（技術的な見落としではなく設計判断）
