# 0006: Phase4 UIデザイン方針（ダークネイビー基調のデザインシステム）

- ステータス: 決定済み・実装済み（Day45/47の一部を前倒し）
- 日付: 2026-08-16（Phase4 Day45〜）

## コンテキスト

Phase4（UI改善）着手にあたり、「ポートフォリオとしての第一印象を高める」というゴールに対し、ユーザーと対話しながらデザイン方針を決定した。以下、決定に至る経緯と根拠を記録する。

## 要件（ユーザーからの初期指定）

- UIデザインは最も重視したい点
- 派手な作り込みより「信頼感」「可読性」を軸にした落ち着いた改善
- サイトをクリックするとブランドロゴ「REMDA」が浮かび上がる演出
- メインカラーはディープネイビー系、文字色は白。暗くなりすぎず、クールなデザイン
- 参考サイト: https://www.scitech.org.au/（西オーストラリア科学館）
- 不動産×データ分析を想起させる画像を配置
- ボタンは丸みを帯びたデザイン
- アニメーションは無料枠のリソース制約を考慮し控えめに

## 参考サイト分析

Browserペインでスクリーンショットが取得できない環境制約があったため、`getComputedStyle()`をJavaScriptで実行し、ページ内の背景色を機械的に抽出する方法で分析した。

- ベース背景: `rgb(8, 6, 30)`（漆黒に近い紺紫）
- アクセント: `rgb(68, 55, 187)` ≈ `#4437BB`（鮮やかなインディゴ/バイオレット）

## 決定事項（AskUserQuestionによる対話で全項目Recommended採用）

| 項目 | 決定内容 | 理由 |
|---|---|---|
| テーマ適用範囲 | 常時ダークネイビーをデフォルト（ライト/ダーク切替は維持） | 「REMDAらしさ」を最も強く出せるため |
| イントロ演出 | 初回訪問時のみ、ロゴがフェードイン→遷移（localStorageでスキップ管理） | 毎回見せると煩わしい、ポートフォリオとしての第一印象は初回で十分 |
| ヒーロー画像 | 外部画像ではなくデータ可視化自体を主役に | 実データ主義（Phase3までの一貫した方針）を継続、無料枠での画像調達コストも回避 |
| アクセントカラー | 鮮やかな青紫1色に絞る | 2026年SaaSダッシュボードのトレンド（後述）とも合致 |
| ボタン | 丸みを帯びたデザイン | ユーザー指定通り |
| アニメーション | 控えめ、機能的なmicro-interactionのみ | リソース制約への配慮 |
| タイポグラフィ | 既存のGeist Sansを継続 | 変更コストが全ページに及ぶため今回は見送り |

## 2026年トレンド調査を踏まえた追加方針

WebSearchで「SaaSダッシュボードUIトレンド2026」「アクセシビリティ・タイポグラフィトレンド2026」を調査し、以下を採用した（ユーザー承認済み）。

**採用**:
- 純黒でなく「真のグレー」ベース（Linear/Supabase/Vercel等の「使い倒すツール」の定石）
- レイヤー型階層表現（shadowでなく背景の明度差でカード階層を表現）
- ダークモード専用のchart配色（彩度を抑えた複数色相、薄いグリッド線）
- **WCAG 2.2 AA準拠**（本文コントラスト比4.5:1、UI要素3:1、visible focus indicator、キーボード操作性）
- 機能的なmicro-interaction（状態を伝える動きのみ）

**見送り**:
- グラスモーフィズム（描画コスト高、無料枠のパフォーマンスに不利）
- 3D要素・没入型演出（実装・パフォーマンスコストが重い）
- 崩したグリッドレイアウト（データテーブル中心の設計と相性が悪い）
- キネティックタイポグラフィ（実務ツールとしては過剰）

## カラートークンの決定（WCAG検証済み）

OKLCH→sRGB変換とWCAG相対輝度計算式を自作スクリプト（一時ファイル、コミット対象外）で実装し、候補色のコントラスト比を計算で検証してから確定した。

```
background: #060b16   foreground: #eff2f6  (17.52:1)
card:       #0c1420   muted-fg:   #9199a5  (6.83:1 on background)
popover:    #121b29   primary:    #535cda  (primary-fg #ffffff: 5.36:1)
border:     #525e72   (3.01:1 on background、UI要素基準3:1をクリア)
```

chart配色（ダークモード専用、彩度を抑えた5色相、いずれも背景とのコントラスト5:1以上）:
```
chart-1: #6875f6 (青紫)   chart-2: #00bdbe (シアン)   chart-3: #e99b2a (アンバー)
chart-4: #f9667a (ローズ) chart-5: #65c86b (グリーン)
```

ライトモードのprimaryも、ブランドの一貫性のため同系の青紫（`#3632b6`、白背景で9.17:1）に統一した。

## 実装上の技術的判断

- **`next-themes`導入**: `attribute="class"`、`defaultTheme="dark"`、`enableSystem={false}`（システム設定への追従はさせず、明示的にライトへ切り替えない限りダークを保つ）
- **`react-hooks/set-state-in-effect`対応**: テーマ切替ボタンのマウント検知は`useSyncExternalStore`で実装。イントロアニメーションはReactの状態管理ではなくCSSアニメーションの`animationend`イベントで完結させ、`useEffect`内での無条件`setState`呼び出しを避けた
- **`--radius`を`0.625rem`→`0.875rem`に拡大**してボタンを丸みを帯びたデザインに
